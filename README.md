# Rana × Sadique — Moonlit Digital Wedding Invitation

A **new website design**, distinct from the cream floral printed card. This is a modern midnight-indigo / lavender, moonlit editorial wedding experience, mobile-first and ready to deploy on **Vercel**. It contains the actual MP3 supplied in the conversation, **not YouTube**. The audio loops and begins when a guest taps **Open your invitation**. Visitors can pause it with the music button in the top bar. Browser policies do not allow guaranteed sound before the opening tap.

## Quick deploy to Vercel

1. Unzip `rana_sadique_moonlit_vercel.zip`. Inside is the `rana_sadique_moonlit_website` folder; keep all files together.
2. Go to [vercel.com/new](https://vercel.com/new), sign in and import a new GitHub repository containing the **contents of this folder**. Or install the Vercel CLI and, inside the website folder, run `npx vercel --prod`.
3. Use Vercel's **Other** framework preset, no build command, and the default root directory. Vercel will host `index.html` and the `api/rsvp.js` function.
4. Vercel will give you a public `.vercel.app` link. Share it only when the RSVP settings below have been completed and tested.

## RSVP: required one-time setup

Because Vercel's static hosting doesn't store or send RSVP responses by itself, the website includes a **serverless RSVP email function** using [Resend](https://resend.com/). The form already calls `/api/rsvp` and will show an honest "not configured" message until the environment variables below are set. No guest's RSVP is silently discarded or marked successful.

Create an account at Resend and set the following **Environment Variables** in your Vercel project's Settings → Environment Variables:

| Variable | Example | Description |
|---|---|---|
| `RESEND_API_KEY` | `re_...` | Secret generated by Resend; NEVER add it to front-end code or commit it to Git. |
| `RSVP_TO_EMAIL` | `host@example.com` | Email address where the bride's family should receive guest replies. |
| `RSVP_FROM_EMAIL` | `Wedding RSVP <rsvp@yourverifieddomain.com>` | Verified sender/domain in Resend. Their test sending address is usually limited to account-owner mailboxes. |

After updating Vercel environment variables, **redeploy** the website. Submit a test RSVP on the public site and check that it arrives in the configured mailbox **before sharing with guests**. Incoming RSVPs are delivered to the hosts by Resend email. This template does not run its own database. Keep the host email and API key private.

If you prefer RSVPs stored in Google Sheets or sent to WhatsApp instead, the API can be changed later; those require choosing an account/recipient first.

## Editing the site

- `index.html`: names, wording, details and the visible website layout.
- `styles.css`: colors, fonts, gradients, animations and device responsiveness.
- `script.js`: animation opening, music, countdown, sharing and RSVP form logic.
- `api/rsvp.js`: Vercel function for emailing RSVP responses with Resend.
- `assets/wedding-nasheed.mp3`: direct audio file (your uploaded clip).
- `assets/venue-qr.png`: original QR image.
- `assets/nikkah.ics` and `assets/reception.ics`: downloadable calendar reminders.
- `assets/social-preview.png`: WhatsApp/social preview image. For a reliably rich preview, replace `og:image` in index.html with the **absolute HTTPS URL** of this image after deploying (for example `https://your-site.vercel.app/assets/social-preview.png`).

## Preview locally

Use `python -m http.server 8000` from inside the website folder and browse to `http://localhost:8000`. Music, countdown, page navigation and map links work. **RSVP only works after the Vercel deployment and environment configuration** (no API on a plain local file server).
